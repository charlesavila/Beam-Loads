# Project Layout

This is a single-file web app. Keep `index.html` at the top level so GitHub Pages can serve it.

- `spec.md` — project requirements and specification.
- `prompts.md` — a log of prompts and work completed.
- `index.html` — the complete web app.
- `00_planning/` — notes, sketches, and planning documents.
- `01_data/` — source data and data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the folder that matches its purpose. Keep app implementation in `index.html`; do not split the app into additional source files.
